Codex ↔ Chat 0.3.4 — 使用说明

这个工具支持 Codex 向你指定的 ChatGPT 对话发送任务和必要材料，并自动取回文字结果或原文件。用户指令或适用项目规则允许协作时才使用；安装、连接和绑定本身不产生协作许可。

首次安装（推荐）
直接把本 ZIP 或本机 ZIP 路径交给 Codex，告诉它安装位置、允许传送材料的目录、目标 Chat 对话完整链接。无需先解压、编辑 JSON、研究 clientId/回调或手算哈希。
示例：请安装到 D:\Tools\codex-chat，材料允许用 D:\Projects\my-app，使用我提供链接的 Chat 对话。

备用手动路径
解压到新建可写目录，确认 Node 24.18 或以上的 24.x x64 已安装，运行 Install.cmd，再让 Codex 完成自有通道配置和绑定。安装入口检查包内文件哈希。缺 Node 时本人确认官方安装。

环境与必要操作
需要 Codex 桌面原生消息工具、当前账号的 Sites 发布能力和私人 MCP 应用连接能力。缺工具或账号能力就报告缺项；普通 CLI 不自动具备整套平台能力。本人完成必要登录、应用连接和平台安全确认，不改变审批、代理、VPN、防火墙或证书校验。

服务与材料
每位用户创建自己的私人固定地址服务，不共用作者后台。选定附件在平台服务中短期保存，不把整个项目存到插件数据库。
当前版本没有本地 reader 和 Cloudflare 临时隧道。Chat 不能直接读本机路径；缺材料时提交需求，Codex 从原授权目录补充。
安装目录和材料目录可不同。每个 Codex 绑定一个 Chat；同一 Chat 不同时绑定多个 Codex，材料目录可以相同。

日常使用
配置成功后复用已有固定地址和绑定，无需每次重新建连接、发布服务或安装。告诉 Codex 本次需要的协作即可。
生图第一条只发画面要求，生成结束后程序自动发送含已核实应用名称和任务信息的导出指令，再取回原图、校验大小与 SHA-256，并清理临时附件。
正文和原文件按必要范围提供；路径、哈希文字和截图不冒充原文件。

等待与限制
空查询和传输在工具程序内处理，不逐轮请求模型 API；宿主续取仍可能产生 Codex 模型用量。
默认文字约 3 分钟、附件约 10 分钟，单次最多 15 分钟。超时保留状态可续等，不无限重试；确认不明时不盲目重发。
单附件最大 16 MiB，开始上传约一小时后到期，读取不续期。过期/删除拒绝读取，闲置物理清理由访问或删除触发。
当前账号真实文件和自动生图导出已验收；独立新用户首次配置、真实第二账号切换和音频感知未标为通过。平台能力、网络和应用工具选用存在外部限制。
