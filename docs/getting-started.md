# 使用指南

## 首次安装

无需先解压。把 ZIP、它的本机路径或下载链接交给 Codex，说明三件事：

1. 工具安装到哪里。
2. 允许发送哪个目录里的材料，可指定“当前项目”。
3. 使用哪个桌面端 ChatGPT 会话，提供会话名；重名时补充项目名，也可提供链接。

例如：

> 请安装这个工具到 D:\Tools\codex-chat，材料允许用 D:\Projects\my-app，目标用桌面端的“测试响应”会话。

Codex 检查环境和文件哈希、安装 skill、配置你自己的私人服务并保存绑定。安装目录与材料目录可以不同；已有配置会先核实再复用，不需要你编辑 JSON 或研究客户端参数。

创建和发布私人服务、检查应用连接由 Codex 自动处理。需要本人登录、平台授权或缺 Node 时的官方安装确认，才按指引操作；自动入口受限时会指出具体页面和动作。

服务发布与应用连接会分别核验。发布后工具暂未出现时，Codex 会刷新工具发现并调用身份探针；需要本人操作时，才引导你到“插件 → 个人 → 由你创建”安装或连接本账号的应用。服务名称相同不表示不同用户共用后台。

需要 Windows x64、Node 24.18 或以上的 24.x x64、Codex 桌面原生消息工具，以及当前账号可用的 Sites 发布和私人 MCP 连接能力。缺少入口时会说明原因。

想手动安装：解压到新建可写目录，运行 Install.cmd，再把上述三项告诉 Codex。

## 日常使用

首次配置成功后直接复用连接，无需重新安装、发布服务或创建 MCP。向 Codex 提出协作要求，或在项目规则中允许它使用 Chat。

> 请让已绑定的 Chat 审核这次改动，取回结果后继续修改。

> 请向 Chat 发送一条生图指令：雨后山巅，两位剑客对决。我自己去 Chat 查看和下载。

> 请按顺序向 Chat 发送三条生图指令：古桥对决、雪山独行、竹林练剑。图片我自己取。

普通审核、规划和文件任务由程序传送必要材料、等待、补充和取回。图片是可选的仅发送功能：你可以一次提供全部画面要求，程序一次只向 Chat 发送一条，上一轮结束后再补发下一张的生图指令，最后一条送达就结束。你在目标 Chat 查看、选择和下载图片；程序不追加导出、不上传或取回图片，也不把指令送达当成出图成功。单次最多 16 条，队列有时限，超时会报告已发送条数并保留剩余指令，不会无限续发。

协作以当前 Codex 会话为主，同一时刻合作一个 Chat，之后可以更换。直接告诉 Codex：“改用‘方案讨论’会话，材料目录不变。”不需要重新安装工具或创建私人服务。

若旧协作尚未完成，可以说：“先保留暂停，改和‘方案讨论’合作。”Codex 会保存旧任务的目标、材料和回执，再更换绑定；之后说“恢复之前的审核”，会继续原任务取结果，不重复发送。暂停只停止本地处理，不会撤回已经发给 Chat 的消息；旧 Chat 仍可能完成原工作。在暂停任务恢复或完成前，不向该旧 Chat 插入新的协作任务。材料目录和账号有变化时一并说明，未说明则沿用授权目录；账号仍按实际登录身份核验。

## 更新已有安装

把新版 ZIP 或下载链接交给 Codex，说明“更新到原安装位置，保留现有账号、材料目录和 Chat 绑定”。无需重新创建私人服务或 MCP 连接；安装入口会核验新版文件并更新已管理的 skill。旧版自动取回图片任务保留记录，当前入口不再续跑。

## 文件与限制

每位用户拥有自己的远程私人服务；选定附件短期保存，取回后自动清理，单文件最大 16 MiB。Chat 缺材料时由 Codex 从授权目录补充，不能自行读本机磁盘。

等待在工具程序内进行，但宿主续取仍可能消耗 Codex 用量。超时保留状态，可以续等。

本机切回原账号后，已在新的 Chat 会话完成合成方案审核与正式结果读回，约 47 秒，原暂停任务保持不变。新账号私人服务和自动连接已核验，其真实任务仍因 Chat 系统错误暂停；首次使用的完整验收和真实多账号完整验收仍待完成。音频感知未通过。完整记录：https://github.com/313715295/codex-chat/blob/main/docs/validation.md
