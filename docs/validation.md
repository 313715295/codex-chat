# 验证记录

版本：0.3.3。整理日期：2026-10-15。

## 已实际验证

- Windows 授权目录精确访问、junction 拦截、目录边界和撤销/停止清理。
- 当前账号真实 Chat 的文字委托、结果提交和 Codex 精确读回。
- 真实附件上传/读回、完整字节与 SHA-256 校验、任务/版本关联及删除后拒绝读取。
- 图片“只发画面要求 → 自动追加一次导出 → 原图下载核验 → 临时附件清理”。
- 导出时不点名应用曾复现工具不可用；点名已核实应用后测试成功，并再次通过本机正式安装入口确认。该确认轮为 1672×941 PNG，约 3.1 MB，程序耗时 5 分 32 秒，自动两条消息，无用户搬运原文件。
- 等待、轮询和传输程序自身没有请求模型 API；宿主续取仍产生模型响应。

开放版本沿用已验收的运行实现，仅整理发布结构、说明、许可证、版本和干净使用包。没有把开发者账号配置或实际图片随仓库发布。

## 未作为通过项

- 第二账号真实 A/B/A 切换；目前只有本地配置与身份保护测试。
- Chat 对音频内容的实际感知测试。
- 任意个人账号、套餐和平台环境的普遍兼容性。
- 长期故障率或全部网络/应用选用异常的解决。

旧临时 reader/隧道验收不作为本版本使用入口，也不随包交付。历史云端回归通过不等于 Windows 或新用户验收通过。请在后续测试中继续区分本地检查、平台连接和真实交互结果。

发布前在 Windows Node 24.18.0 x64 完成75项协作入口测试、12项附件核心测试、内存 SQLite 的 MCP smoke 检查及后端完整生产构建。使用包逐文件 SHA-256 检查和 ZIP 内容复核通过。测试不会自动向真实 Chat 发送内容。
