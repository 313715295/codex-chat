# 验证记录

版本：0.3.9。整理日期：2026-10-16。以下记录区分既有账号历史通过项与新账号接入检查，不代表所有账号均可使用。

## 本次提示词修正与暂停范围

首条普通委托点名实际已核实的私人应用，精确服务地址和工具前缀仍固定在任务中；不按应用同名猜测身份。图片、音频参考材料先尝试实际预览，只有任务需要保存、解析或验收字节时才要求 Chat 下载整文件；本地及服务端的传输校验保留。相关消息、账号保护和纯生图分支由本地回归覆盖。

本次图片参考材料复测暴露了工具发现和感知不稳定，以及不必要的完整下载、校验研究造成的额外耗时。提示词已精简，真实 Chat 测试随后按用户要求暂停；最新五条刀法生图指令在目标检查时被 systemError 阻止，0/5 发送，不计为生图通过。未启用长度上限自动交接或自动切换 Work。

## 切回原账号并更换 Chat

2026-10-16，本机通过原生 owner-private 记录和独立 MCP 探针核实原账号及已连接的私人通道，按会话名找到新的 Chat。旧账号未完成审核被显式保留暂停，未重发、未标为完成；原包和状态文件哈希保持不变。

同一 Codex 改用新 Chat，直接提供合成重命名方案，Chat 返回两项具体审核意见并正式提交私人结果；约 46.9 秒完成。任务、版本、委托回执、校验短语与材料 SHA-256 一致，本轮执行占用已释放。程序发送原生委托 1 次、查询正式结果 4 次，没有重建或重新安装服务，也没有要求用户选择应用或搬运结果。

这是切回既有账号后的单次文本审核验证，不覆盖本轮文件传输、图片、多账号完整验收或另一台机器首次安装。暂停与恢复、同账号更换 Chat 及恢复原绑定另有本地程序回归；旧账号真实任务仍暂停。

## 图片范围

图片功能由用户选择。程序逐条发送生图指令，用户在 Chat 查看和下载。sent 仅表示指令送达；原生摘要没有提供成图内容，本次未核验实际成图、数量、质量或原文件。

旧版自动图片回传曾有成功记录，后续复测在导出轮反复报告工具不可用；提前添加协作说明也未解决。0.3.6 停用该入口，旧包保留记录，不自动继续生成或导出。此版本不声称修复了自动图片回传。

## 等待与本地检查

普通任务在程序内约每 30 秒查询正式结果，每五分钟仍无结果时核对对应轮次，最多提醒补交一次。图片队列约每 30 秒核对前一轮，空检查不会单独返回模型；两条路径均有时限和恢复状态，回执不明不盲目重发。

程序自身不调用模型 API，宿主续取仍可能产生模型请求。真实三条图片队列执行阶段为 3 次 Codex 响应，其中等待续取 2 次；准备、独立核验和最终报告另计，Chat 内部请求数不可读。没有实现闲置会话事件唤醒。

2026-10-16，单独在当前宿主内做本地挂起验证，无真实 Chat、网络或服务修改：约 3 秒等待记录 1 次 Codex 模型请求，约 65 秒等待被宿主分段，初始调用和续取共 2 次。请求数按本会话实际用量记录去重统计，不计可变上下文 token。结果表明单加服务端长等待不能在当前入口实现零模型续等，因此本版保留结果查询与五分钟兜底，不宣称服务端推送已实现。

Windows Node 24.18.0 x64 下，119 项协作测试、12 项附件测试及 MCP smoke 检查通过。模拟检查覆盖暂停恢复及原绑定保留、同账号更换 Chat、首次发布顺序、连接发现延迟、Already installed、Windows 构建包结构、五分钟漏交恢复、Chat 系统错误、图片队列顺序、超时恢复、身份失败和回执丢失。这些不代替真实故障注入或新用户验收。
