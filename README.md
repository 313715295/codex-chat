# Codex ↔ Chat

让 Codex 在你允许的范围内与指定 ChatGPT 对话协作：发送任务和必要材料，等待 Chat 完成，取回文字结果或原文件，继续当前任务。

适用于审核、规划、设计、图片生成和文件处理。这是可选工具：用户指令或适用项目规则允许协作时才使用；安装和保存绑定本身不会发送消息或材料。

你可以直接把 ZIP 或下载链接交给 Codex，告诉它：

1. 工具安装到哪里。
2. 允许传送哪个目录里的材料。
3. 使用哪个 ChatGPT 对话。

例如：

> 请安装这个 Codex ↔ Chat 工具到 D:\Tools\codex-chat。材料允许使用 D:\Projects\my-app，目标 Chat 对话是我提供的完整链接。完成必要配置后，在我要求协作时使用。

材料目录与安装目录可以不同。请提供真实目录或“当前项目”，由 Codex 核实实际路径；不需要手改 JSON、clientId、回调或哈希。

## 当前支持的环境

- Windows x64，Node.js **24.18 或以上的 24.x x64**。
- Codex 桌面宿主提供原生会话读取、消息发送工具。
- 首次配置需要当前账号可用的 **Sites 发布能力和私人 MCP 应用连接能力**；登录或平台安全确认仍由本人完成。
- 目标 ChatGPT 对话必须属于当前可用账号，并能使用该用户自己连接的结果/附件应用。

这不是给普通终端单独运行的完整聊天机器人。安装 skill 不会凭空提供桌面消息或平台发布能力；缺少入口时会报告缺项。新账号能否首次配置取决于实际平台能力，尚未完成独立新用户验收。

## 它如何协作

1. Codex 通过桌面原生消息向目标 Chat 发送任务。
2. 正文直接提供；需要原文件时，通过当前账号自己的私人结果/附件服务上传选定文件。
3. Chat 通过 MCP 提交结果；缺材料时返回具体需求，Codex 从已授权目录补充，再发送新版本。
4. 工具程序等待结果、下载原文件并校验完整大小和 SHA-256，清理临时附件。
5. Codex 取得实际结果后继续当前任务。

**图片生成采用两条消息**：第一条只发画面要求；生成结束后，程序自动发送包含已核实应用名称与任务信息的原图导出指令。路径、文件名、截图或哈希文字都不冒充原文件。

消息发送与唤醒走桌面原生工具；MCP 负责结果和附件，不负责主动给聊天发消息。Chat 不安装 Codex 侧 skill。连接应用后的工具选用仍受平台影响，程序会引导使用已核实应用，不能保证所有平台或网络异常都被排除。

## 服务与目录

每位用户创建并拥有自己的私人服务，不共用作者后台。首次成功配置后复用固定地址，无需每次新建连接、购买域名或重启临时隧道。

当前版本**不包含本地 reader，也不使用 Cloudflare 临时隧道**。Chat 不能自行访问你的本地磁盘；缺材料由 Codex 在授权范围内补充。私人服务仍是远程 MCP，选定附件会在平台服务中短期保存，不是纯离线通道，也不会把整个项目存进插件数据库。

每个 Codex 任务绑定一个 Chat；同一 Chat 不同时绑定给多个 Codex。不同绑定可以使用同一个材料目录。已有待完成任务会阻止更换绑定和账号，避免结果串线。

## 日常使用

首次安装和连接完成后，正常协作不再重复安装、发布服务或配置客户端。目标或材料目录变化时，告诉 Codex 更新绑定即可。

程序内处理空查询、自动导出和文件传输，不逐轮调用模型 API。不过宿主等待续取仍可能产生 Codex 模型用量，不能承诺整个流程零 token。默认文字任务等待约 3 分钟，附件任务约 10 分钟，单次最长 15 分钟；超时保留状态，可以续等，不无限重试。

## 源码与开发

| 路径 | 内容 |
| --- | --- |
| `source/collaboration/` | 本地绑定、执行保护、消息等待、附件收发、安装与打包 |
| `skill/codex-chat-delegate/` | Codex 使用入口与必要参考 |
| `source/results-attachments-template/` | 每个用户独立发布的私人结果/附件服务模板 |
| `scripts/` | 测试、使用包构建与发布检查 |
| `docs/` | 用户、开发与验收说明 |
| `downloads/` | 与源码版本一致的干净 Windows 使用包 |

开发测试与构建：

```powershell
cd source/results-attachments-template
npm run install:ci
cd ../..
node scripts/test.mjs
node scripts/release.mjs
```

后端完整依赖安装与构建见 [开发说明](docs/development.md)。当前真实验收范围见 [验证记录](docs/validation.md)。
